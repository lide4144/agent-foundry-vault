# 模板怎么用

本目录包含两类模板：收件箱/工具卡保持小白五字段；概念、实体、对比、查询卡带齐 LLMWiki 正式页字段。它们已经包含可直接填写的正文，不是模板规格说明。

## 何时用

想快速创建结构一致的笔记，又不想从空白页开始时。

## 三步操作

1. 选择最接近当前任务的模板。
2. 手工复制成新文件，或使用 Obsidian 自带 Templates 功能插入；不安装插件也能使用。
3. 替换标题与提示文字，只添加真实内容和已存在的链接。

## 常用模板

- `模板-通用收件箱.md`：暂存闪念、资料和问题。
- `模板-工具卡.md`：沉淀可复用步骤。
- `模板-概念卡.md`：解释定义、原理和边界。
- `模板-实体卡.md`：记录具体对象及其来源。
- `模板-对比卡.md`：并列证据、差异和有条件结论。
- `模板-查询卡.md`：保留问题、检索过程、证据和缺口。

## 完成标准

- [ ] 收件箱和工具卡只要求五类 Frontmatter 字段。
- [ ] Wiki 卡保留 `title/updated/tags/sources` 等正式页字段；发布前补齐来源。
- [ ] 模板提示已被真实内容替换。
- [ ] 来源已填写或明确为“本人想法”。
- [ ] 不依赖社区插件也能正常阅读。

## 常见错误

- 把模板原文件直接改成具体笔记。
- 保留全部提示语，误以为已经完成。
- 为了自动化增加未经批准的脚本。
- 在模板中预埋尚不存在的内部链接。
