# 世界书源：{{条目名}}

本模板记录稳定语义，不代表可直接导入的 JSON。最终字段和值必须按项目 manifest 锁定的目标环境导出。

## 何时用

一段设定需要按常驻或关键词规则进入上下文时。

## 三步操作

1. 写清条目解决什么问题。
2. 明示 strategy、keys、position、recursion。
3. 在真实目标环境测试触发、不触发和递归。

## 条目

~~~yaml
name: "{{条目名}}"
enabled: true
strategy:
  type: selective
  keys: []
  keys_secondary:
    logic: and_any
    keys: []
  scan_depth: same_as_global
position:
  type: "{{目标环境支持的位置}}"
  role: system
  depth: 0
  order: 100
recursion:
  prevent_incoming: false
  prevent_outgoing: false
  delay_until: null
content: |
  {{真正进入上下文的内容}}
~~~

## 完成标准

- [ ] strategy 有明确理由。
- [ ] keys 是真实触发词；常驻条目明确为空。
- [ ] position 已在目标版本核对。
- [ ] recursion 的进出方向均已决定。
- [ ] 已测试误触发和递归放大。

## 常见错误

- 用“高频”代替 keys。
- 把加载策略写进 scan_depth。
- 省略递归方向，直到条目互相放大。
- 复制旧项目 JSON 路径而未核对目标版本。
