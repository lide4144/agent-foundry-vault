# 写回候选怎么用

## 何时用

Agent 或人工提出正式知识修改，但尚未完成证据、冲突、权限和差异审核时。

## 三步操作

1. 建立候选稿，写明目标、来源和冲突。
2. 生成或手工整理改动前后差异。
3. 按安全写回 SOP 审核；不通过就保留、退回或归档。

## 完成标准

- [ ] 候选与正式知识明确分离。
- [ ] 人工可以只看本文件就理解拟议改动。
- [ ] 未审核内容没有写入正式页。

## 常见错误

- 把候选目录当作自动写回队列并无人复核。
- 隐去互相矛盾的来源。
- 直接修改 `raw/`。
