# 收件箱怎么用

收件箱负责“先接住”，不要求第一次就分类正确，也不应成为永久仓库。

## 何时用

- 只有一个念头，还不知道属于哪类。
- 刚收集到网页、对话、截图说明或课程摘记。
- Agent 提出了一项尚未审核的知识修改。

## 三步操作

1. 用 `templates/模板-通用收件箱.md` 记录内容和来源。
2. 写清下一步：保留、核对、整理或删除候选。
3. 每周把值得保留的内容移入工具库、Wiki 保留目录或写回候选流程。

## 三个入口

- `10-收件箱/闪念/`：一句话灵感或问题。
- `10-收件箱/待整理/`：已有材料，但尚未提炼。
- `10-收件箱/写回候选/`：Agent 或人工建议修改正式知识的候选稿。

## 完成标准

- [ ] 每条内容都有能看懂的标题。
- [ ] 尽可能记录了来源。
- [ ] 每条内容都有明确下一步。
- [ ] 每周至少清理一次，不把收件箱当归档。

## 常见错误

- 无来源地粘贴整段内容。
- 看到 Agent 输出就直接移动到正式知识区。
- 同一内容重复收集多次却不合并。
- 因为分类困难而完全不记录。

涉及正式知识修改时，先读 [[10-收件箱/写回候选说明]]。
