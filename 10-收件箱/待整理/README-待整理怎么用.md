# 待整理怎么用

## 何时用

已经有材料和来源，但还没提炼成工具卡、概念卡或实体卡时。

## 三步操作

1. 记录来源，不先改写原始材料。
2. 用自己的话写三行摘要。
3. 判断它应进入工具库、概念、实体、对比或查询目录。

## 完成标准

- [ ] 来源可追溯。
- [ ] 摘要与原文摘录能区分。
- [ ] 有明确整理去向。

## 常见错误

- 把复制内容当作自己的结论。
- 没核对实体身份就合并同名条目。
- 原文与摘要混在一起。
