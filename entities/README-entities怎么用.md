# entities 怎么用

这里放有明确名称、可单独介绍和引用的对象，例如人物、软件、作品、组织或项目。

## 何时用

页面主要回答“它是谁或是什么对象、有哪些事实、与谁相关”时。

## 三步操作

1. 复制 `templates/模板-实体卡.md`。
2. 先核对正式名称、别名和同名对象，避免错误合并。
3. 按来源写事实并先放 `10-收件箱/写回候选/`；冲突转入查询或对比记录，审核后再发布到本目录。

## 完成标准

- [ ] 实体身份明确，不与同名对象混淆。
- [ ] 事实与判断分开。
- [ ] 来源可追溯。
- [ ] 关系链接只指向真实存在的页面。

## 常见错误

- 把同名人物、作品或软件版本合成一页。
- 把推测写成事实。
- 只记录简介，不记录来源。
- 为追求完整一次填入大量未经核验内容。
