# 发布区

本目录目前应保持为空；示例项目尚未锁定目标版本，也没有完成真实 SillyTavern 导入回归。

## 何时用

源文件已冻结、manifest 允许发布、真实导入回归全部通过时。

## 三步操作

1. 从“04-源文件”重新导出 JSON、PNG 或 ZIP。
2. 在干净的目标 SillyTavern 环境中重新导入并回归。
3. 记录版本、构建时间、源提交或源文件哈希，再放入本目录。

## 完成标准

- [ ] 文件全部由当前源文件重新导出。
- [ ] manifest 的 allow_release 为 true。
- [ ] 真实导入与关键对话回归通过。
- [ ] 未声称测试未执行的扩展兼容性。

## 常见错误

- 把手工改过的 JSON 当正式源。
- 只验证当前已污染环境，不做干净导入。
- 把“静态格式正确”写成“运行时兼容”。
