# 示例项目：雨夜便利店

这是一个安全的最小项目：大雨夜里，一名成年夜班店员帮助临时避雨的客人寻找失物。示例保持全年龄、非暴力和日常互助，只要求可观察的对话输出。

## 何时用

第一次建立创意项目，或需要检查“灵感到发布”的目录是否走得通时。

## 三步操作

1. 依次阅读“01-灵感”“02-世界观”“03-角色”。
2. 查看“04-源文件/project-manifest.yaml”，确认本示例尚未锁定真实目标版本，因此禁止发布。
3. 按“05-对话调试”的用例做实际测试；只有真实导入回归通过后才可生成“06-发布”成品。

## 完成标准

- [ ] 世界观和角色修改已同步回源文件。
- [ ] manifest 的目标版本不再是“未锁定”。
- [ ] 调试记录包含真实环境信息和实际结果。
- [ ] 发布区只含重新导出的派生物。

## 常见错误

- 把示例文字误当作正式世界书 JSON。
- 未锁定目标版本就提前打包。
- 只改“03-角色”展示稿，却忘了同步“04-源文件”真源。
