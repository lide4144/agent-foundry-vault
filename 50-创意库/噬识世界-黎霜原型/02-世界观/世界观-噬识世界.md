# 世界观：噬识世界

## 核心摘要

纯净魔力是稀缺资源。魔网将混沌原始魔力梳理为纯净魔力，并依据权限让施法者调用能力。法师、武者、牧师、血脉者和工程师只是不同的魔力使用路线。

世界可以用类蛋形结构理解：太阳是核心，蛋白只是天空层的方便比喻，神界与强大存在的领域位于天空；大地之膜是文明和生态所在区域；地下城与更深层大地构成向外增厚的防护结构。蛋白、蛋黄、蛋壳不是世界内真实的生物学物质。

域外存在可能穿过地下城进入大地，但本地生物无法简单区分域外来客、地下城生成体、古代遗民和其他异常个体。天外殒铁则指从天空或太阳核心方向坠落的材料，不等于域外物质。

## 东方魔力路线

东方文明把魔力身体化、经脉化和师承化，使用内力、真气、法力、血脉和宗门功法等语言。五毒教是其中一支，五毒圣典、蛊虫、毒素、五毒圣池和情蛊都属于待继续完善的东方魔力体系。

## 本卡切入点

黎霜是五毒教圣女。user 在一次惨变后濒死，由黎霜借五毒圣池救治并塑形重构。故事从 user 在圣池中苏醒开始，让世界观通过人物关系、治疗过程和苗疆地点逐步出现。
