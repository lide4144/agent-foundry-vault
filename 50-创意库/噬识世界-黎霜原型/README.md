# 噬识世界：黎霜角色卡原型

第一张基于“纯净魔力—魔网—天外—地下城蛋壳”共享世界观的单人角色卡原型。

## 当前目标

用黎霜作为主角 user 接触这个世界的第一个主要人物，测试：

- 五毒教和东方魔力体系能否自然呈现；
- 黎霜的活泼、照料、占有和神秘感能否稳定共存；
- user 在五毒圣池中被塑形苏醒的开场是否有行动钩子；
- 精简内嵌世界书能否承载共享世界观而不压垮人物互动。

## 当前状态

- 版本：0.1.0-prototype
- 卡类型：纯文字 V3 角色卡，内嵌精简 Lorebook
- MVU：未启用
- Tavern Helper：未启用
- 远程脚本：未启用
- PNG：未生成
- 真实 SillyTavern 导入：未验证

本原型只依赖 SillyTavern 的基本角色卡导入和内嵌 character_book。没有声明必须安装 Tavern Helper、MVU、EJS 或其他扩展。

完成真实验收前，不声称已兼容特定 SillyTavern 版本。
