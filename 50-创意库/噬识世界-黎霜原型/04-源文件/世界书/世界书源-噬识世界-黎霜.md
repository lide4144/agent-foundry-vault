# 世界书源：噬识世界·黎霜原型

## 条目：共享世界核心

- strategy: constant
- keys: []
- position: before_char
- recursion: non-recursable
- content: 纯净魔力稀缺。魔网梳理混沌原始魔力并按权限分配能力。法师、武者、牧师、血脉者与工程师都是不同的魔力使用路线。世界可用类蛋形结构理解：太阳是核心，天空位于核心与大地之间，大地之膜承载文明，地下城与更深层大地构成向外增厚的防护结构；蛋白、蛋黄、蛋壳只是创作者方便使用的结构比喻，不是世界内真实物质。天外殒铁来自天空或太阳核心方向，不等于来自蛋壳之外的域外物质。

## 条目：东方魔力与五毒教

- strategy: keyword
- keys: [五毒教, 五毒圣典, 苗疆, 圣女, 蛊]
- position: after_char
- recursion: non-recursable
- content: 东方文明把魔力身体化、经脉化和师承化，常称内力、真气或法力。西方文明则可能更倾向于以法术、权限、学院、工程和组织份额描述同一套魔力。五毒教是苗疆的东方魔力组织，五毒圣典、蛊虫、毒素、血脉和圣池构成其特殊知识体系。不要把东方武侠写成与魔网无关的另一种超自然力量。

## 条目：五毒圣池

- strategy: keyword
- keys: [五毒圣池, 圣池, 塑形, 重构]
- position: after_char
- recursion: non-recursable
- content: 五毒圣池是五毒教最重要的治疗与仪式地点之一。当前 user 在池中被重构，受损身体、经脉和魔力回路正在重新连接。池水、毒素、蛊虫和圣女权限共同作用，但具体机制仍由剧情逐步揭示，不要一次性罗列全部答案。

## 条目：情蛊

- strategy: keyword
- keys: [情蛊, 心跳, 痛觉, 共鸣]
- position: after_char
- recursion: non-recursable
- content: 情蛊是黎霜施加于 user 的双向魔力联系，可表现为心跳共鸣、痛觉共享、生命状态感知和距离限制。情蛊不是无条件替 user 做决定的控制器；它更适合作为关系压力、照料、危险预警和情绪拉扯的机制。具体边界待剧情确认。

## 条目：域外与地下城

- strategy: keyword
- keys: [地下城, 蛋壳, 域外, 外界来客]
- position: after_char
- recursion: non-recursable
- content: 地下城与更深层大地构成抵御域外的保护结构。域外存在可能穿过地下城进入大地，但本地生物通常无法仅凭外貌判断其来源；地下城生成体、古代遗民、魔力变异者和真正域外来客可能难以区分。天外殒铁指从天空或太阳核心方向坠落的材料，不等于域外物质。

## 条目：天器

- strategy: keyword
- keys: [天器, 铸剑山庄, 天外殒铁, 神兵]
- position: after_char
- recursion: non-recursable
- content: 古代铸剑山庄曾以天外殒铁、强者传承结晶和目前失传的特殊技术打造十二件天器。每件天器都能承载极高权限和强大力量，甚至可能破坏世界结构。天器的具体名单、能力和出世地点尚未确定，不要擅自补全为固定答案。

## 条目：噬识魔尊

- strategy: keyword
- keys: [噬识魔尊, 噬识, 魔尊]
- position: after_char
- recursion: non-recursable
- content: 噬识魔尊是共享世界观中的另一位重要背景人物，也是域外来源难以辨认问题的特殊案例。他的真实目的、经历和后续行动只在剧情需要时揭示。黎霜目前不应无缘无故知道他的全部故事。
