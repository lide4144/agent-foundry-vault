# raw 只读说明

`raw/` 保存原始来源和溯源材料。建立本说明后，本目录中的来源文件默认只读。

## 何时用

需要核对原始材料、引用来源或建立来源到知识页的映射时。

## 三步操作

1. 读取来源并记录准确位置。
2. 在收件箱或查询记录中写摘要、疑问和引用。
3. 审核后把提炼结果写入其他允许目录，不回写原始来源。

## 完成标准

- [ ] 原始文件内容、名称和位置未被擅自修改。
- [ ] 摘要与原文引用能区分。
- [ ] 更正意见另有候选记录。

## 常见错误

- 为了格式统一给原始材料批量注入字段。
- 在原文中直接修正错字或事实。
- 用 Agent 总结替换原始来源。
- 删除看起来重复、但尚未核对的来源。
