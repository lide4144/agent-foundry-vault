# comparisons 怎么用

这里放对比、冲突分析和方案取舍。它记录“为什么这样判断”，不只给一个胜负结论。

## 何时用

- 两个实体、概念或方案需要按相同维度比较。
- 多个来源对同一事实存在冲突。
- 需要保留采纳与不采纳的理由。

## 三步操作

1. 复制 `templates/模板-对比卡.md`，明确比较对象和共同维度。
2. 并列记录证据、差异和未知项。
3. 给出有条件结论；证据不足时保留待复核状态，先走写回候选再发布。

## 完成标准

- [ ] 比较维度一致。
- [ ] 双方来源都保留。
- [ ] 事实、评价和建议分开。
- [ ] 结论写明适用条件。

## 常见错误

- 先有结论再挑选支持证据。
- 用不同维度比较两边。
- 删除不支持当前判断的来源。
- 把版本差异误判成事实冲突。
