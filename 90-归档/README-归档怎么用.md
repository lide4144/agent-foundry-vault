# 归档怎么用

归档用于保存不再活跃、但仍有追溯价值的内容。归档不是垃圾桶，也不是删除前的免责区。

## 何时用

- 文档已停用或被新版替代。
- 查询已关闭，但过程仍值得保留。
- 候选方案被否决，但需要保留决策依据。

## 三步操作

1. 按 [[90-归档/归档检查清单]] 确认不再活跃、没有未完成写回。
2. 记录归档原因和替代位置；只链接真实存在的替代文件。
3. 移动后检查受影响链接，并按仓库规则维护 `index` 与 `log`。

## 完成标准

- [ ] 能说明为什么归档。
- [ ] 未归档仍在使用的唯一版本。
- [ ] 移动后的链接和索引已检查。
- [ ] `raw/` 没有被当作归档来源随意搬动。

## 常见错误

- 为了目录整齐归档尚未判断的内容。
- 把秘密、缓存和临时文件长期塞进归档。
- 移动文件后不检查链接。
- 归档后删除决策理由。
