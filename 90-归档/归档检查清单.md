# 归档检查清单

## 何时用

准备把停用、废弃或旧版内容移入 `90-归档/` 时。

## 三步操作

1. 判断是否真的不再使用。
2. 检查替代文件、链接、索引、日志和未完成审批。
3. 小范围移动并验证；批量归档前先备份和请求确认。

## 归档前

- [ ] 内容已完成、停用或有明确替代版本。
- [ ] 没有尚未裁决的写回候选。
- [ ] 不是 `raw/` 原始来源。
- [ ] 已记录归档原因。
- [ ] 已确认替代文件真实存在。

## 归档时

- [ ] 只移动已确认范围。
- [ ] 不顺手改名或重写正文。
- [ ] 高风险或批量操作已有备份和人工确认。

## 归档后

- [ ] 已检查受影响内部链接。
- [ ] 已维护对应 `index` 与 `log`。
- [ ] 搜索仍能找到归档内容。
- [ ] 新人入口没有继续推荐停用页面。

## 完成标准

- [ ] 归档原因、时间背景和替代关系可理解。
- [ ] 活跃工作流未被破坏。
- [ ] 可以安全恢复到归档前状态。

## 常见错误

- 把“暂时不知道放哪里”当作归档理由。
- 批量移动后才发现链接失效。
- 归档唯一有效的操作说明。
- 用归档代替真正的备份。
