# 从这里开始

> Agent Foundry Vault智能体工坊：Obsidian × LLMWiki × Hermes 的 Agent 训练、知识与运维中枢

这不是一套要求你先学完再使用的系统。第一周只做三件事：**记下来、找得到、再整理**。

在 Obsidian 选择“打开本地库文件夹”，指向整个 `Agent Foundry Vault智能体工坊`。第一天不需要安装社区插件；暂时不用 Obsidian 时，任意 Markdown 编辑器也能打开这些文件。

## 何时用

- 第一次打开本仓时。
- 不知道内容该放哪里时。
- 想确认下一步该做什么时。

## 三步开始

1. 打开 [[00-开始这里/10分钟首跑]]，写下一条真实内容。
2. 按 [[00-开始这里/7天上手路线]] 每天完成一个小练习。
3. 迷路时看 [[00-开始这里/系统地图]]；看不懂词时查 [[00-开始这里/术语表]]。

## 第一周只用五个字段

| 字段 | 用途 | 示例 |
|---|---|---|
| `type` | 这是什么 | `inbox`、`tool`、`concept`、`entity` |
| `status` | 现在做到哪 | `draft`、`candidate`、`active`、`archived` |
| `created` | 创建日期 | `2026-07-17` |
| `tags` | 少量检索词 | `入门`、`安全` |
| `source` | 内容从哪里来 | 网址、书名、对话或“本人想法” |

Agent 的置信度、证据账本、运行轨迹等机器字段放在后台，不要求新手填写。

## 完成标准

- [ ] 已写下一条不是“测试”的真实内容。
- [ ] 知道临时内容先放 `10-收件箱/`。
- [ ] 知道正式知识进入根目录的 `concepts/`、`entities/`、`comparisons/` 或 `queries/`。
- [ ] 知道 `raw/` 只读，不能直接改。

## 常见错误

- 一开始就设计几十个标签。
- 还没写内容就先安装很多插件。
- 把 Agent 输出直接当成已验证事实。
- 在没有备份和差异预览时批量改文件。

仍有疑问时看 [[00-开始这里/常见问题FAQ]]。
