# 术语表

## 何时用

遇到不懂的词时查一项即可，不需要一次背完。

## 三步使用

1. 找到陌生词。
2. 只读“白话解释”和“你要做什么”。
3. 回到正在做的任务。

| 术语 | 白话解释 | 你要做什么 |
|---|---|---|
| Vault | Obsidian 打开的整个本地文件夹 | 把它当成仓库根目录 |
| Markdown | 以 `.md` 保存的纯文本格式 | 正常写标题、段落和列表即可 |
| Frontmatter | 文件顶部两个 `---` 之间的字段 | 第一周只填五个字段 |
| 双链 | 指向另一篇真实笔记的链接 | 只链接已经存在的文件 |
| 收件箱 | 暂时接住未整理内容的地方 | 先记录，之后再分类 |
| 概念 | 定义、原理或术语 | 放入根目录 `concepts/` |
| 实体 | 有名字、可单独介绍的对象 | 放入根目录 `entities/` |
| raw | 原始来源或溯源材料 | 只读，不原地改写 |
| Query | 一次查询及其证据记录 | 放入根目录 `queries/` |
| 写回 | 把审核后的候选内容写入正式知识页 | 先看差异、再审批、再写入 |
| LLMWiki | 供 LLM 检索和组织知识的兼容结构 | 保留五个根目录，不随意改名 |
| Harness | 用来运行、评测、回放 Agent 的脚手架 | 新手先使用，不必先修改 |
| Trace | 一次 Agent 运行的过程记录 | 由后台维护，不写入首周字段 |
| Schema | 规定数据有哪些字段和格式 | 由系统维护，不要求新手设计 |
| Dataview | 可选的 Obsidian 社区查询插件 | 不安装也能使用本仓 |

## 完成标准

- [ ] 能分清概念、实体和 raw。
- [ ] 知道 Harness、Trace、Schema 属于后台概念。
- [ ] 知道 Dataview 是可选项。

## 常见错误

- 为了看懂全部术语而暂停实际记录。
- 把“索引里存在”误认为“事实已经审核”。
- 把 LLM 生成内容误认为原始来源。
