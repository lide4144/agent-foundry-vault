# 10 分钟首跑

目标不是学完系统，而是留下第一条以后还能找到的真实内容。

开始前，在 Obsidian 选择“打开本地库文件夹”，指向整个 `Agent Foundry Vault智能体工坊`。不装任何社区插件也能完成本页。

## 何时用

第一次使用本仓，或很久没用、想重新开始时。

## 三步操作

### 第 1 步：选一条真实内容

任选一种：

- 今天突然想到的点子。
- 一个以后还会查的问题。
- 一段需要整理的资料。
- 一个反复使用的方法。

### 第 2 步：用模板写进收件箱

复制 `templates/模板-通用收件箱.md`，把新文件放到 `10-收件箱/待整理/`。手工复制时把 `{{title}}`、`{{date}}` 换成真实标题和 `YYYY-MM-DD` 日期，并填写 `source`（没有外部来源就写“本人想法”）；其他内容可以边用边补。

如果你习惯 PowerShell，也可以先预览再创建：

```powershell
node scripts/new-inbox-note.mjs "我想整理的主题"
node scripts/new-inbox-note.mjs "我想整理的主题" --apply
```

正文至少写三行：

1. 这是什么？
2. 为什么值得留下？
3. 下一步要做什么？

### 第 3 步：决定暂时放哪里

- 还不确定：留在 `10-收件箱/待整理/`。
- 是可复用步骤：以后整理到 `30-系统工具库/`。
- 是概念或具体对象：以后整理到根目录 `concepts/` 或 `entities/`。
- 是 Agent 建议修改正式知识：进入 `10-收件箱/写回候选/`，先审核，不直接覆盖。

## 完成标准

- [ ] 文件已保存。
- [ ] 标题以后能看懂。
- [ ] 正文至少三行。
- [ ] `source` 已填写或明确写成“本人想法”。

## 常见错误

- 为了选“完美目录”卡住十分钟以上。
- 把模板说明原样保留，却没写真实内容。
- 把网页全文直接复制进正式知识页。
- 认为必须安装 Dataview 才能开始。
