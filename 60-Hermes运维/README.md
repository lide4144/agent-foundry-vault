# Hermes 运维

这里保存可供人审阅的运行摘要、Skill 登记、决策、指标、事件、变更和复盘。它不是 Hermes 的真实 HOME，也不是秘密、完整记忆或大体积 trace 的存放地。

## 何时用

- 一次运行值得以后复现或排错时。
- 准备评审、启用或退役一个 Skill 时。
- 发生故障、策略变化或需要周期复盘时。

## 三步操作

1. 判断记录类型：运行、Skill、决策、指标、事件、变更或复盘。
2. 使用对应最小模板，只写必要摘要和可定位证据。
3. 回读检查秘密与夸大表述，再决定留在当前区或归档。

## 目录

| 目录 | 用途 |
|---|---|
| 01-运行记录 | 一次任务的目标、结果、验证与后续 |
| 02-Skills | 候选、已批准目录和已退役 Skill |
| 03-决策 | 有替代方案的长期选择 |
| 04-指标 | 从真实遥测汇总的趋势，不要求手工日记 |
| 05-事件 | 故障、降级、误写和安全异常 |
| 06-变更 | 配置、Skill、路径和流程变化 |
| 07-复盘 | 从运行与事件中提炼改进 |
| 08-归档 | 已替代记录及替代关系 |
| config | 需人工合并的配置示例 |
| bundles | 需人工安装的 Skill bundle 示例 |

## Vault 外的数据

以下内容不得进入本 Vault：

- 实际 HERMES_HOME 与运行状态数据库；
- MEMORY、USER 等真实记忆内容的完整副本；
- API Key、Cookie、令牌、恢复码和私钥；
- 完整私聊转录；
- 大体积原始 trace、模型请求响应和缓存。

Vault 只保留脱敏摘要、外部 artifact 引用、哈希和恢复所需的最少定位信息。

## Token 与成本

不要求人工每天登记 Token。只有运行时或提供商真实提供计量时才汇总；拿不到就写“未知”，不能估算后冒充精确值。指标按有意义的运行、版本或周期聚合。

## Skill 状态

- 候选：尚未批准，不能假设 Hermes 会加载。
- 已启用：已批准放入外部 Skill 目录；是否被当前 Hermes 配置发现，仍须用真实命令确认。
- 已退役：不再推荐调用，但保留替代关系和审计记录。

文件出现在“已启用”目录不等于已安装、已加载或已通过运行时验证。

## 完成标准

- [ ] 记录类型正确。
- [ ] 没有秘密、完整记忆或大 trace。
- [ ] “已安装、已加载、已验证”均有真实命令或运行证据。
- [ ] 失败和未知没有被省略。
- [ ] 后续动作有负责人或明确写“待决定”。

## 常见错误

- 把 Vault 当成 HERMES_HOME 备份。
- 每天手工抄 Token，数据仍不准确。
- Skill 放入目录后直接声称运行时已启用。
- 为方便排错把完整私聊和环境变量复制进事件记录。
