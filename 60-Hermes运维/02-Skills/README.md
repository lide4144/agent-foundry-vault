# Skills

这里是 Skill 的评审与版本目录，不是 Hermes 内置安装器。

## 何时用

一个流程会重复使用、单靠短记忆不够，或现有 Skill 需要升级和退役时。

## 三步操作

1. 在“候选”写用途、触发条件、权限与验证计划。
2. 人工审阅并完成至少一次真实使用验证。
3. 批准后放“已启用”；替代或停用后放“已退役”并写替代项。

## 完成标准

- [ ] SKILL.md 有合法 frontmatter 和清楚流程。
- [ ] 权限与副作用已明示。
- [ ] 是否被真实 Hermes 发现有独立验证。
- [ ] 更新与退役有替代关系。

## 常见错误

- 把长知识百科全部塞进 SKILL.md。
- 目录名写“已启用”就声称运行时加载成功。
- external_dirs 可写却误认为是只读沙箱。

实际启用前阅读[已启用说明](已启用/README.md)和[配置示例](../config/README.md)。
