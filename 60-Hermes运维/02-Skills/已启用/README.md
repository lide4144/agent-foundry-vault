# 已启用 Skill 目录

“已启用”表示已被本仓治理流程批准并放入可发现目录，不表示当前 Hermes 进程已发现、加载或调用成功。

## 何时用

候选已审阅、真实用例通过，并准备通过 skills.external_dirs 暴露给 Hermes 时。

## 三步操作

1. 核对 Skill 名称、来源、版本和权限。
2. 人工把本目录加入 Hermes 配置，或使用受控安装流程。
3. 用 Hermes 的 Skill 列表、查看和真实调用验证，再把证据写入运行记录。

## 完成标准

- [ ] 配置由人核对并备份。
- [ ] 真实 Hermes 能发现目标 Skill。
- [ ] 至少一次调用符合预期。
- [ ] external_dirs 的文件系统权限符合预期。

## 常见错误

- 把本 README 的存在当安装证明。
- 忘记本地同名 Skill 可能遮蔽外部版本。
- 认为 external_dirs 是隔离边界；只要 Hermes 进程可写，Skill 管理动作就可能修改其中文件。
