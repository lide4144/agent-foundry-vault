# 运行记录

## 何时用

一次任务产生了可复用结果、失败教训、正式写回或需要后续跟进时。

## 三步操作

1. 记录目标、输入引用和允许动作。
2. 写实际结果、验证与未完成项。
3. 大 trace 放 Vault 外，只在此保留 artifact 路径或哈希。

## 完成标准

- [ ] 能回答“做了什么、改了什么、怎么验证”。
- [ ] 未记录秘密、完整提示词或完整私聊。
- [ ] 未把未执行检查写成已通过。

## 常见错误

- 把每次闲聊都建成运行记录。
- 只写成功结论，不写失败与限制。
- 把大段 trace 粘进 Markdown。
