# 看板与索引怎么用

看板用于回看和决定下一步，不保存唯一事实。基础版完全手工维护，不依赖任何插件。

## 何时用

- 每周整理收件箱时。
- 想查看待复核、写回候选、冲突或归档任务时。
- 已经积累真实内容，想按字段做可选查询时。

## 三步操作

1. 先使用 [[80-看板与索引/手工看板]]，手工写下本周重点。
2. 每周清掉已完成项目，并把长期内容移到正确模块。
3. 只有确认需要自动查询时，才参考 [[80-看板与索引/可选-Dataview看板]]。

## 完成标准

- [ ] 不安装插件也能看见当前重点。
- [ ] 看板只引用真实文件，不制造空链接。
- [ ] 已完成项目及时清理或归档。
- [ ] 看板内容丢失不会导致知识源丢失。

## 常见错误

- 为了自动化先装插件，实际还没有真实数据。
- 把看板当作正式知识正文。
- 自动查询结果未经审核就触发写回。
- 长期保留已经完成的任务，导致看板失真。
