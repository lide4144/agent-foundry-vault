# 系统工具库怎么用

工具库只放能反复照做的方法、规范、SOP 和安全清单。每张工具卡解决一个问题。

## 何时用

- 同一件事已经做过两次，想让下一次更稳。
- 一个操作有误删、覆盖、断链或越权风险。
- 想把口头经验改成别人能复现的步骤。

## 三步操作

1. 先确认这是一套可复用方法，而不是某个具体对象的知识。
2. 复制 `templates/模板-工具卡.md`，写清输入、步骤和完成标准。
3. 自己按步骤走一遍；有歧义就继续精简或补例子。

## 完成标准

- [ ] 一张工具卡只解决一个明确问题。
- [ ] 步骤不依赖作者脑中的隐藏知识。
- [ ] 高风险动作写明停止点和人工确认点。
- [ ] 文档没有要求用户执行不存在或未验证的命令。

## 常见错误

- 把背景理论、FAQ、规范和多个 SOP 全塞进一页。
- 只写“注意安全”，不说明何时停止。
- 为了统一格式覆盖仓库局部规则。
- 没实际走过步骤就标记“在用”。
