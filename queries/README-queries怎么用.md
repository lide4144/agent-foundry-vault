# queries 怎么用

这里保留查询问题、检索过程、证据、冲突和待复核结论。查询记录不是自动生效的正式知识。

## 何时用

- 一个问题需要多源检索或实体消歧。
- 想保留 Agent 查询结果以便复核、回放或以后写回。
- 结论尚不足以进入概念、实体或对比页。

## 三步操作

1. 复制 `templates/模板-查询卡.md`，写清问题、范围和期望证据。
2. 记录来源、冲突、缺口与暂定结论。
3. 需要写回时建立候选差异，进入安全写回流程。

## 完成标准

- [ ] 问题和范围明确。
- [ ] 结论能回到具体证据。
- [ ] 未确认内容明确标记待复核。
- [ ] 写回没有绕过候选与审批。

## 常见错误

- 只保存最终回答，不保存问题和来源。
- 把检索不到写成事实不存在。
- 把查询缓存当作长期知识。
- 未核对冲突就直接更新实体页。
