# concepts 怎么用

这里放定义、原理、术语和可复用知识，不放具体人物、软件实例或项目档案。

## 何时用

页面主要回答“这是什么意思、如何运作、边界是什么”时。

## 三步操作

1. 复制 `templates/模板-概念卡.md`。
2. 用自己的话写定义、例子和不适用范围。
3. 先保存到 `10-收件箱/写回候选/`；核对来源、同名条目并审核后，再发布到本目录。

## 完成标准

- [ ] 一句话定义清楚。
- [ ] 有例子和边界。
- [ ] 来源可追溯。
- [ ] 与实体页职责没有混淆。

## 常见错误

- 复制百科定义却没有自己的解释。
- 把某个具体软件的全部档案写进概念页。
- 只有标签，没有正文。
- 未审核就由 Agent 自动覆盖已有定义。
